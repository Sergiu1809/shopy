## Approach
Scaffold the brief §6 layout with the least code that makes each criterion checkable.
**Backend:** a uv project in `backend/` (`pyproject.toml` + `uv.lock`) with a FastAPI app
exposing `GET /health` → 200 `{"status": "ok"}`, one pytest test via FastAPI's
`TestClient`, ruff and mypy (strict) configured in `pyproject.toml`; the worker is a
placeholder `python -m worker` loop that logs "idle" and sleeps (no DB, no outbox).
**Web:** the official `create-vite` `react-ts` template in `web/`, trimmed to an empty
shell (`<h1>Shopy</h1>`), its oxlint config (`.oxlintrc.json`), a `typecheck` script, vitest + Testing
Library + jsdom with one render test. **Compose:** one `docker-compose.yml` with db
(`pgvector/pgvector` pg16 image + an init SQL that creates `vector` and `unaccent`), api
and worker (same backend image), web (Vite dev server), minio + a one-shot `minio/mc`
bucket-init service, mailpit; every credential is interpolated from `.env`.
**CI:** a new `.github/workflows/ci.yml` on every push with four jobs (backend, web,
ledger, gitleaks). **Hook:** a `.pre-commit-config.yaml` with only the official
gitleaks hook. No reuse target exists in code yet (no code in the repo); the nearest
existing example is `.github/workflows/team-checks.yml`, whose checkout/ledger-lint
steps `ci.yml` copies.
Rejected: a Makefile now (only `make seed` uses it, P1); a Postgres service in CI (the
P0 test does not touch the DB; testcontainers arrive with P1 models); `vite-plugin-pwa`,
a router, TanStack Query, pydantic-settings, structlog (no P0 criterion needs them).

## Risks
- **Docker unreachable from WSL** → the builder cannot prove AC 2; fallback MT-001, and
  the user enables WSL integration (one setting, reversible).
- **MinIO images:** MinIO stopped publishing new community Docker images in late 2025;
  older `minio/minio:RELEASE.*` tags remain. Pin one existing tag (and a matching
  `minio/mc` tag); the builder verifies they pull. If they are gone, stop and ask (do
  not swap in another S3 server: the brief names MinIO).
- **pre-commit golang bootstrap:** the gitleaks hook is `language: golang`; pre-commit
  downloads Go on first run (network, ~1 min). If that fails, fallback hook
  `gitleaks-docker` (needs Docker) or a user-installed gitleaks with `gitleaks-system`;
  report, do not install system-wide.
- **gitleaks-action licence:** free for personal-account repos; an organization repo
  would need `GITLEAKS_LICENSE`. The repo is under a personal account (Q-007).
- **Bind mounts and HMR on Windows:** fine while the repo lives in the WSL filesystem;
  if the developer runs Compose from a Windows path, Vite may need polling
  (`server.watch.usePolling`) — not added unless MT-001 shows it is needed.
- **Port clashes** on 5432/8000/5173 with local services: documented in MT-001 notes only.
- Easy to reverse: everything is new files; nothing touches data.

### Assumptions

- **A1 · Versions.** Python 3.12 (D-003); Postgres image `pgvector/pgvector:<0.8.x>-pg16` pinned to an exact existing tag; Node 26 (`node:26-alpine`, CI node 26: the current LTS line and the local version); `minio/minio` and `minio/mc` pinned `RELEASE.*` tags; `axllent/mailpit:v1.<x>` pinned; uv image and `setup-uv` pinned; GitHub actions at their major tags (`@v4`/`@v5`/`@v2`) like `team-checks.yml`. - **A2 · Health body** `{"status": "ok"}` (the AC only asks for 200; brief §14 gives no shape).

- **A4 · Postgres credentials.** Add `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` to `.env.example` (not in §18) so Compose has no hard-coded password (PATTERN-013). MinIO root user/password reuse `S3_ACCESS_KEY` / `S3_SECRET_KEY`. Alternative: hard-code local-only creds in `docker-compose.yml`.
- **A5 · Extensions via an init SQL script** in Compose for local dev. P1's first Alembic migration must still `CREATE EXTENSION IF NOT EXISTS` both (Neon has no init scripts). Alternative: leave extensions to P1 and only prove they are *available* now.
- **A6 · `dangerouslySetInnerHTML` lint rule now**, through oxlint's built-in `react/no-danger` (the linter create-vite 9.3.4's react-ts template ships; TypeScript 7). _Adjusted 2026-11-18:_ the original ESLint `no-restricted-syntax` choice was dropped because the current template ships no ESLint and typescript-eslint 8.73 does not support TS 7. Rejected: ESLint + TS 6 downgrade (6 deps), older create-vite 8.x.
- **A7 · `PRICE_*`** stays a comment in `.env.example` ("unit prices per provider; names defined with the usage ledger in P3"): the brief gives no concrete names, and inventing them is out of bounds.
- **A8 · `ruff format --check`** in CI and §2 alongside `ruff check` (formatting gate from day one). Drop it if only `ruff check` is wanted.
- **A9 · Hook wiring** with the pre-commit framework run through `uvx` (no system install; one committed config), not a hand-written `.githooks/pre-commit` (that needs a system gitleaks binary and `core.hooksPath` per clone). - **A10 · CI trigger** `on: push` only (brief §17 "every push"); PRs are covered because their branches are pushed. `team-checks.yml` stays as is.
